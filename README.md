🌾 AgriGuard

AgriGuard is an Agricultural Intelligence System designed to improve food security, farmer income, and agro-input integrity in Uganda using data science and machine learning.


Problem Statement

Farmers in Uganda face:
- Unpredictable crop prices
- Fake agricultural inputs (seeds, pesticides)
- Poor access to market intelligence
- Climate-related production risks


Solution

AgriGuard provides:

- Crop price forecasting using ML
- Fake agro-input detection system
- Market intelligence and risk insights
- Decision support for farmers and policymakers



Features (MVP)
- Price prediction model
- Basic input authenticity verification
- Data visualization dashboard


Tech Stack

- Python
- Pandas / NumPy
- Scikit-learn
- Streamlit
- Matplotlib / Seaborn



Future Expansion

- Weather-based yield prediction
- Satellite agriculture monitoring
- SMS-based farmer alerts
- National food security index



Goal

To build a scalable agricultural intelligence system that supports farmers, government, and agro-industries in Uganda.
